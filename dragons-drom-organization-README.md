# Dragons-Drom

Engineering-first organization for production-grade AI, ML systems, and full-stack platforms.

## What We Build

- Agentic AI platforms for automation, orchestration, and research workflows
- Applied ML products for prediction, NLP, vision, and domain intelligence
- Full-stack systems designed for operational reliability and scale

## Standards We Enforce

- Security by default in design, implementation, and release
- Accessibility and usability as first-class quality requirements
- CI/CD quality gates for lint, tests, and build verification
- Operational readiness with clear deployment and monitoring guidance
- Repository collaboration context through .claude/CLAUDE.md

- Tier B: Strategic repos under hardening and release automation
